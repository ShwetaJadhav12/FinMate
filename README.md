
# FinMate – Smart Personal Finance Tracker

**FinMate** is a modern Android application that helps users track expenses, manage monthly budgets, and analyze spending patterns efficiently. The app focuses on simplicity, automation, and a clean user experience with real-time cloud sync.


## 🚀 Features

**Secure Authentication**
  Email & password authentication using **Firebase Authentication**.

**Expense & Transaction Management**
  Add, edit, and delete expenses with automatic category detection.

**Transaction Sorting**
  Sort transactions by **date, amount, or category** for better financial insights.

 **Voice-Based Expense Input**
  Log expenses using Android Speech-to-Text with keyword-based parsing.

**Monthly Expense Analytics**
  Visualize spending patterns using interactive charts.

**Export Monthly Summary**
  Save monthly expense summary cards as images in local storage.

**Cloud Firestore Integration**
  Real-time, user-specific data storage and synchronization.

---

## 🛠 Tech Stack

* **Language:** Kotlin
* **UI:** Jetpack Compose (Material 3)
* **Architecture:** MVVM
* **Backend:** Firebase Authentication, Cloud Firestore
* **Charts:** Compose-based chart libraries
* **APIs:** Android Speech-to-Text

---

## 🧩 Architecture

FinMate follows **MVVM architecture** for scalability and clean code:

* **Model:** Firebase data models
* **View:** Jetpack Compose UI
* **ViewModel:** Business logic & state management
